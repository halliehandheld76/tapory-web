## 🔍 How to Organize Links

Efficiency matters when you save many pages. Use these methods to keep your links tidy.

*   **Creating Categories:** Click the "New Category" button. Type the name and press Enter. Move your links into these folders by dragging and dropping them.
*   **Adding Tags:** Right-click a link and select "Edit Tags." Type your chosen label and save.
*   **Deleting Items:** Select a link and press the Delete key. The software asks if you are sure before it removes the entry.

## 🛡 Security and Privacy

Your bookmarks contain personal information. tapory-web avoids data harvesting. The application stores everything in a local database file. No one else has access to these files unless you share them. You control your information at all times. If you delete the application, your data remains in a local folder until you choose to remove it.

## 🔧 Frequently Asked Questions

**Does the app connect to the internet?**
The app checks for software updates. It does not send your bookmarks to any server.

**How do I update the application?**
When a new version is available, the app shows a notification at the top of the window. Click the notification to download the latest setup file. Running the new installer replaces the older version while keeping your bookmarks intact.

**Can I run the app on multiple computers?**
Yes. You can install the tool on as many Windows machines as you own. Note that your bookmark database stays on the local drive of each computer.

**The app runs slow. What should I do?**
Close other applications that use high memory. If the issue keeps happening, restart the computer to clear system cache.

**Where does the app store my data?**
The app creates a folder in your user profile path. Do not move or rename files inside this folder unless you intend to perform a full backup.

## 📁 Troubleshooting

*   **Installer will not start:** Check your internet connection or try to restart your browser.
*   **Missing bookmarks after import:** Ensure your primary browser is closed when you start the import process.
*   **The app refuses to open:** Check your task manager to see if another instance of the app is running. End that task and try again.
*   **Missing labels:** Refresh the category list by clicking the view menu and selecting "Reload."
